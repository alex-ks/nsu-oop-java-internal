# Internal materials for NSU OOP Java course

## Темы для разгоночных семинаров
- Hello, world! Знакомство с ide, структурой сорцов, моделью запуска
- Знакомство с git: что должно быть в репозитории, gitignore
- Знакомство с Unit-testами, линковка библиотеки руками
- Знакомство с системами сборки, вытаскивание библиотек из репозитория

## Правила оформления:
- Code style: https://google.github.io/styleguide/javaguide.html
- В репозитории должны быть только:
  -  исходники (папка src)
  -  файлы gradle
  -  .gitignore
  -  .iml проекта Idea

## Общая информация
- Для сдачи используем Github
- 16 задач
  - 6 - на тройку
  - 11 - на четвёрку
  - 14 - на пятёрку
- Если в течение календарного месяца не было сдано ни одной задачи, то на студента налагается штраф в -1 задачу
- На семинарах проводим пятиминутки
  - 75% пятиминуток - +1 задачка
  - Вопросы собираем по предыдущей лекции
  - Листочки студенты приносят сами, на первом семинаре объявляем об этом
  - После сбора листочков зачитываем вопросы - пусть отвечают хором
- Сэмпловый проект не предоставляем, студенты сами нарабатывают его на первых трёх семинарах
- Принимаем задачки на ноутбуке преподавателя
  - Репозиторий выкачивается за сутки до проведения семинара
- Через месяц/с середины семестра начинаем требовать сдачу через ПРы
- Для всех публичных классов и методов должны быть комментарии с описанием

## Примеры пятиминуток
- Каким будет доступ у метода без указания спецификатора?
- Могут ли быть статические методы у интерфейса?
- Чем отличается inner-класс от nested (по синтаксису и смыслу)
- Можно ли вызвать приватный метод вне класса?
- Как обеспечивается кросс-платформенность Java?
