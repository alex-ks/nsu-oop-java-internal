## Кратко о Java

- Control flow - почти как в C
- Типы данных - отличаются
  - Какие типы помните в C?
  - Value-типы и Reference-типы (и как они выглядят в C)
    - Value-типы копируются при передаче в/из функции
    - Для Reference-типов копируется только ссылка, объект остаётся тот же
    - Указатели - Reference, остальное - Value
  - В Java примитивные типы - value, все остальные - Reference
    - class'ы и enum'ы (наследники Object)
  - Бога ради, не зовите сборщик мусора руками!

## Hello, world!

Создаём файлик `App.java`:

```Java
public class App {                                // В Java нет свободных функций, поэтому сначала нужен класс.
    public static void main(String[] args) {      // Объявляем точку входа a la int main(). Обязана быть public.
        System.out.println("Hello, world!");
    }
}
```

- `public` - определяет область видимости (здесь - видно всем), как для класса, так и для метода
- `static` - определяет scope (или контекст) существования полей и методов, как глобальный (на уровне класса, а не конкретного объекта)

Имя класса должно совпадать с именем файла, иначе компилятор скажет нам, что мы неправы. То же касается объявления нескольких публичных классов в одном файле.

Компилируем:

```bash
javac App.java
```

Здесь `javac` - компилятор. Видим, что появился файл `App.class`. Запускаем:

```bash
java -classpath . App
```

Здесь:
- `java` - виртуальная машина
- `-classpath .` - указываем путь к директории, из которой будут загружаться классы
- `App` - имя одного из загруженных классов, который содержит точку входа

Если всё пошло хорошо, то в консоли мы увидим `Hello, world!`.

Горюем, что как-то сложна по сравнению с C. Радуемся, что больше делать этого не придётся.

Оставшуюся часть семинара пишем генератор чисел Фибоначчи:

```Java
public class FibonacciGenerator {
    private long[] cache;

    public FibonacciGenerator(int elementsCount) {
        if (elementsCount <= 0) {
            return;
        }
        cache = new long[elementsCount];  // by default all values are zero.
        // Initialize our sequence cache with first two values.
        cache[0] = 1;
        if (elementsCount > 1) {
            cache[1] = 1;
        }
    }

    public long getNthNumber(int n) {
        if (cache == null || n < 0 || n >= cache.length) {
            return -1;
        }
        if (cache[n] != 0) {
            return cache[n];
        } else {
            cache[n] = getNthNumber(n - 1) + getNthNumber(n - 2);
            return cache[n];
        }
    }
}
```

Ради развлечения можно посчитать сложность по времени метода `getNthNumber`.
