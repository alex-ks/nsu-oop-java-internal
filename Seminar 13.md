## Пятиминутка

- Как в Java написать конструктор класса-наследника, если в базовом классе нет конструктора без аргументов?
- Можно ли создать объект, если у его класса не объявлен конструктор? Почему?
- Какое значение будет у полей объекта, если они не проиницализированы в конструкторе?
- Какова модель исполнения Java?
- Что такое ссылка в Java?

*Ответы:*
- Через ключевое слово `super`: `class B extends A { public B { super(/*some args*/); } }`
- Да, т.к. компилятор сгенерирует пустой конструктор без параметров
- `0` для примитивных типов, `false` для `boolean` и `null` для всех остальных- `0` для примитивных типов, `false` для `boolean` и `null` для всех остальных
- Java-код компилируется в платформенно-независимый байткод, который затем исполняется другой программой - виртуальной машиной
- Абстракция указателя на область кучи, в которой располагается объект


## Ещё разок о Race condition

- Ситуация, когда два потока не синхронизуются при доступе к разделяемому ресурсу, из-за чего результат работы программы не определён ввиду случайности порядка исполнения команд из разных потоков

Race Condition может, но необязательно приводит к порче данных. Основная проблема при Race Condition - недетерминированность результата исполнения.
