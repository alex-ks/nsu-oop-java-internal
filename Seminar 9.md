## Пятиминутка

- Чем отличается статическая типизация от динамической?
- Какие основные виды полиморфизма вы знаете?
- Может ли внутренний (inner) класс получить доступ к полям внешнего класса? Если да, то к каким?
- Чем внутренний (inner) класс отличается от вложенного (nested) класса?
- Можно ли создать экземпляр внутреннего (inner) класса из статического метода этого класса?

*Ответы:*
- В статической все типы известны на этапе компиляции, а в динамической - только во время исполнения
- Ad-hoc, параметрический, подтипов
- Может, ко всем, в том числе и приватным
- Экземпляр внутреннего класса содержит ссылку на экземпляр внешнего, и не может существовать без него; вложенный класс не ссылается на внешний и такой зависимости по времени жизни не имеет
- Нет, т.к. статический метод выполняется вне контекста объекта (на самом деле можно, если в этом методе создать экземпляр внешнего класса)

# Ещё немного про типизацию

- Статическая/динамическая
- Сильная/слабая
  - Сильная практически не допускает преобразований типов, слабая - практически не ограничивает
- Явная/неявная
  - Нужно ли явно определять типы объектов при создании

Эти категории ортогональны друг другу. Например:
- JavaScript - динамическая, слабая, неявная
- Python - динамическая, сильная, неявная
- C, C++ - статическая, слабая, явная
- Java, C# - статическая, сильная, явная
- Haskell, F# - статическая, сильная, неявная
