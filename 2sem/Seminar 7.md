# Семинар 2020.03.19

## Пятиминутка

- Представим, что вы пишите приложение для диспетчерской в пиццерии. Вам нужно хранить идентификаторы (уникальные) всех заказов, которые ещё не были доставлены (доставленные должны удаляться). Какую структуру данных вы для этого выберете и почему?
- В чём отличие методов `Thread.interrupted()` и `Thread.currentThread().isInterrupted()`?
- Влияет ли на значение этих флагов выброс `InterruptedException` (если да, то как)?
- Как реализовать оператор `instanceof` через Reflection API?
- Как в Java сделать метод с переменным количеством аргументов? Как потом обрабатывать эти аргументы в коде?

В последних двух вопросах напишите код.

*Ответы*
- Set (HashSet/TreeSet), т.к. она гарантирует уникальность элементов и позволяет быстро удалять/добавлять элементы без оглядки на их порядок
- Статический `Thread.interrupted` сбрасывает флаг "прерванности" после вызова, а `isInterrupted()` - нет
- Выброс InterruptedException сбрасывает флаг "прерванности" в `false`
- `boolean isInstanceOf(Class c, Object o) { return c.isInstance(o); }`
- `void doSmth(TArg... args) { /* args instanceof TArg[] == true */ }`
