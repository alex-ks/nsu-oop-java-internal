# Семинар 2020.05.21

## Пятиминутка
- Как исполнить скрипт на Groovy из Java- или Groovy-кода - так, чтобы из него можно было получить значение?
- Чем отличаются свойства `Closure.delegate` от `Closure.owner` в Groovy?
- Что такое иерархия?
- Сформулируйте принцип разделения интерфейсов
- Сформулируйте принцип единственности ответственности

*Ответы*
- Один из способов: создать объект класса `Binding` для задания и получения переменных, создать от него `GroovyShell` и вызвать `shell.execute`
- Owner - объект, в контексте которого было создано замыкание (`this` для метода или внешнее замыкание для вложенного замыкания), и в котором runtime Groovy будет пытаться найти методы и переменные. Delegate - изначально то же самое, но может быть изменён в рантайме - тогда сначала runtime будет искать имена в Owner, затем - в Delegate
- Упорядочение абстракций путем расположения их по уровням
- Программные сущности не должны зависеть от методов, которые они не используют
- Каждый объект должен иметь одну ответственность и эта ответственность должна быть полностью инкапсулирована в класс. Все его поведения должны быть направлены исключительно на обеспечение этой ответственности. "У класса должна быть только одна причина для изменения"
