# Семинар 2020.03.25

## Пятиминутка

- Нужно ли перекомпилировать программу JavaFX при изменении UI, написанного на FXML? Почему?
- В чём заключается паттерн MVC? Дайте определение каждому его элементу.
- Как из Java-кода обратиться к элементу UI, объявленному в FXML?

*Ответы*
- Нет, так как FXML-разметка загружается в рантайме
- MVC - способ проектирования UI-приложения как композиции трёх элементов:
  - Модель - абстракция данных и методы для работы с ними; представляет собой логику приложения без привязки к представлению
  - Представление (View) - сущность, получающая данные из модели и представляющая их пользователю
  - Контроллер - получает от View пользовательские запросы, запрашивает их исполнение модели и передаёт результаты обратно View
- Создать класс, содержащий элемент в качестве поля (одноимённого с id элемента), пометить его аннотацией @FXML, прописать в FXML имя этого класса в атрибуте fx:controller
