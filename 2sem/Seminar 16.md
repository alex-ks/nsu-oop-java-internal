# Семинар 2020.06.04

## Пятиминутка

- Что такое protection domain в Java?
- При взаимодействии объектов классов из разных доменов, по какому принципу определяется набор прав в текущей точке стека вызовов?
- Какие основные виды полиморфизма вы знаете?
- Что такое таблица виртуальных методов?
- Пусть даны два класса:
```Java
class A {
  private String a = "A";

  A() {
    initialize();
  }

  void initialize() {
    System.out.println(a);
  }
}

class B extends A {
  private String b = "B";

  B() { }

  @Override
  void initialize() {
    System.out.println(b);
  }
}
```

Что будет напечатано в консоль при конструировании объекта B (`new B()`) *и почему*?


*Ответы:*
- Множество классов, объединённых общим набором разрешений.
- Набор прав определяется как пересечение прав всех доменов, классы которых участвуют в стеке вызова
- Ad-hoc, параметрический, подтипов
- Способ реализации полиморфизма подтипов; таблица, в которой хранятся указатели (адреса) на реализации методов
- `null`. Конструктор базового класса вызывается перед конструктором наследника; при этом в конструкторе `A` происходит вызов переопределённого метода `B.initialize` - но, т.к. конструктор `B` вызван не был, то его поля ещё не инициализированы.
