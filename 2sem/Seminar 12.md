# Семинар 2020.05.07

## Пятиминутка
- Что такое пакет в Java?
- Что такое абстрактный класс?
- Что такое абстрагирование?
- О чём говорит принцип открытости-закрытости?
- Что в определении модуля значит "сильно связные внутри, но слабо связанные между собой"?

*Ответы*
- Способ группировки классов и ограничения пространства имён; способ представления модуля в Java
- Класс, часть методов которого не определена, но может быть доопределена в наследниках
- Выделение существенных характеристик некоторого объекта, отличающих его от всех других видов объектов, и игнорирование несущественных; определение его концептуальных границ с точки зрения наблюдателя
- Классы должны быть закрыты от изменения, но открыты для расширения; новое поведение лучше добавлять с помощью наследования
- Внутри модуля классы могут свободно ссылаться друг на друга; наружу модуль должен предоставлять небольшой круг публичного API с малой вложенностью - тогда изменения внутри модуля не повлекут изменения в других модулях
