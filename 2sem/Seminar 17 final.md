10.  Напишите метод (функцию), который для данного объекта напечатает все его публичные методы (например, `void printMethods(Object target)`)

*Ответы:*
1. Нечто, обладающее
  - состоянием (перечень свойств и их текущие значения)
  - поведением (реагирует на сообщения в зависимости от текущего состояния: меняет своё состояние и посылает сообщения другим объектам)
  - идентичностью (то, что отличает объект от других)
2. Совокупность соглашений о функциональности элемента програмы
3. Абстрагирование, инкапсуляция, модульность, типизация, иерархия, [параллелизм, сохраняемость]
4. Принцип подстановки Лисковой:
  - Пусть q(x) является свойством, верным относительно объектов x некоторого типа T. Тогда q(y) также должно быть верным для объектов y типа S, где S является подтипом типа T
  - Функции, которые используют ссылки на базовые классы, должны иметь возможность использовать объекты производных классов, не зная об этом.
5. Абстрактный класс может иметь определения методов и поля, интерфейс - только объявления
6. Пометить класс как `final`
7. Checked-исключения необходимо либо явно обрабатывать с помощью try-catch, либо указывать в сигнатуре метода через `throws`. Для unchecked исключений этого делать не нужно.
8. Generics компилируются в класс, где параметр заменяется на `Object` и вставляются приведения типов (т.е. для любого значения параметра используется один и тот же класс). Поэтому все значения параметра должны быть наследниками `Object`  а примитивные типы таковыми не являются
9. Скомпилируется, при исполнении выбросится `ClassCastException`. Потому что ArrayList<Integer> компилируется в ArrayList<Object>, и сохранение в него строки является корректной операцией. Но для присвоения компилятор вставит приведение типов - а оно выбросит исключение в runtime
10. Код:
```Java
void printMethods(Object target) {
    Class clazz = target.getClass();
    for (Method method : clazz.getMethods()) {
        System.out.println(method.getName());
    }
}
```
