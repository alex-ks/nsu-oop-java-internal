# Семинар 2020.02.28

## Пятиминутка

- Какой класс и какой его метод являются точкой входа для приложения JavaFX?
- Чем сцена-stage отличается от сцены-scene?
- Для чего служат панели (Pane)?
- Что такое свойство (property) в JavaFX?
- Где находится точка отсчёта координат JavaFX и как расположены координатные оси?

*Ответы*
- `javafx.application.Application.start`
- Stage - это абстракция окна приложения, а сцена - это контейнер для дерева UI-элементов
- Панели служат для группировки нескольких элементов на одном уровне UI-дерева и регулируют их расположение на сцене
- Свойство - это объект, содержащий некоторое значение, которое можно привязать к некоторому источнику (в т.ч. к другому свойству)
- Точка (0, 0) расположена в левом верхнем углу окна, ось по горизонтали - x (растёт вправо), по вертикали - у (растёт вниз)
