# Семинар 8

## Пятиминутка

- Какими способами можно использовать ключевое слово `final`?
- Пусть есть класс `A` с методом `boolean doSmth(B b, C c);`. На его примере перечислите все способы передать этот метод в качестве лямбда-выражения и чем они отличаются.
- Есть ли из лямбда-выражений доступ к переменным из окружающей области видимости?
- Можно ли с помощью Stream API создать бесконечный поток? Если да, то как?
- Как с помощью Stream API найти максимальное нечётное число в списке `List<Integer> lst`?

*Ответы:*
- Три способа:
  - `final` для переменной - означает, что *присвоение* можно сделать только один раз
  - `final` для класса - означает, что от него нельзя отнаследоваться (`extends`)
  - `final` для метода - означает, что его нельзя перезаписать (`override`)
- Создание лямбды:
  - `(b, c) -> { return a.doSmth(b, c); } // bool(B, C)`
  - `(b, c) -> a.doSmth(b, c) // bool(B, C)`
  - `a::doSmth // bool(B, C)`
  - `A::doSmth // bool(A, B, C)`
- Есть, все переменные из окружающего scope можно использовать, но как будто они были объявлены как final
- `Stream.iterate`, `Stream.generate`
- `lst.stream().filter(n -> n % 2 == 1).max(Integer::compareTo).orElse(-1)`
